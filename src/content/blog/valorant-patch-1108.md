# VALORANT パッチ11.08がきた！｜大規模バランス調整の全貌をお届け

![patch](/pcgame/valorant/patch/1108/image2.png)

## パッチ11.08の概要

2025年のシーズン終盤を迎え、VALORANTに大規模なバランス調整が実施されました。今回のパッチ11.08は、**戦術的な駆け引きを重視**し、アビリティーとガンプレイのバランスを見直す重要なアップデートです。

### パッチの主な目的

- **競技的な対話の強化** - 攻撃側と防衛側の駆け引きをより戦略的に
- **適応と戦略の重視** - 無造作なユーティリティー使用を抑制
- **カウンタープレイの機会増加** - 対抗手段をより明確に

## エージェントアップデート

### 全般的な変更

パッチ11.08では、各種デバフ効果に統一性を持たせ、プレイヤーの反応をより直感的にしました。

#### 視界悪化の調整
対象エージェント：フェイド、オーメン、レイナ、スカイ
- **視認範囲拡大**: 5m → **7m**

#### スタン効果の統一
対象エージェント：ブリーチ、ゲッコー、ネオン、アストラ
- **スタン時間**: 全て **2.5秒** に統一

#### スティム効果の統一
対象エージェント：ブリムストーン、KAY/O、レイナ
- リロード時間短縮: **90%**
- 発射速度上昇: **10%**
- 武器構え時間短縮: **90%**
- ブレ回復速度上昇: **10%**

## イニシエーター大幅調整

イニシエーターは固有アビリティーのクールダウンが延長され、より戦略的な使用が求められます。

### ブリーチ

**フォールトライン**
- クールダウン: 40秒 → **60秒**
- 発動時間短縮: 1.2秒 → **1.1秒**
- スタン時間: 3.5秒 → **2.5秒**

**フラッシュポイント**
- フラッシュ時間: 2秒 → **2.25秒** (強化)

**ローリングサンダー**
- 範囲幅: 23m → **18m**
- スタン時間: 6秒 → **4秒**
- 必要ポイント: 9 → **8**

### フェイド

**ホウント**
- クールダウン: 40秒 → **60秒**
- 発動時間: 2秒 → **1.5秒**

**ナイトフォール**
- 効果時間: 12秒 → **8秒**
- 範囲幅: 24m → **20m**
- 衰弱ダメージが時間経過で減少せず、常に**75ダメージ**を維持

### ゲッコー

**全般**
- 回収クールダウン: 10秒 → **20秒**

**ウィングマン**
- 体力: 80 → **60**

**スラッシュ**
- 体力: 200 → **180**

### KAY/O

**ゼロ/ポイント**
- クールダウン: 40秒 → **60秒**

**フラッシュ/ドライブ**
- 下手投げフラッシュ時間: 1.5秒 → **2.25秒** (強化)

**ヌル/コマンド**
- 発射速度上昇: 15% → **10%**
- 武器構え時間短縮効果追加: **10%**
- ブレ回復速度上昇追加: **10%**

### ソーヴァ

**リコンボルト**
- クールダウン: 40秒 → **60秒**

## デュエリスト調整

### ネオン

**ハイギア**
- バッテリー完全回復時間: 20秒 → **60秒** (大幅延長)
- フルバッテリーダッシュ時間: 12秒 → **16秒**

**リレーボルト**
- スタン時間: 3.5秒 → **2.5秒**

### レイナ

**リーア**
- 体力: 80 → **60**

**エンプレス**
- リロード時間短縮: 25% → **10%**
- 発射速度上昇: 15% → **10%**
- 武器構え速度: 25% → **10%**
- ブレ回復速度: 25% → **10%**

### ヨル

ヨルは大幅な弱体化を受けました。チーム連携がより重要になります。

**ゲートクラッシュ**
- 体力: 60 → **20** (大幅減少)
- テレポート時に音が発生するように変更

**フェイクアウト**
- フラッシュ時間: 3秒 → **2秒**

**ブラインドサイド**
- フラッシュ時間: 1.75秒 → **1.5秒**
- フラッシュ減衰を他エージェントに合わせて統一

**ディメンショナルドリフト**
- ドリフト中にブラインドサイドやフェイクアウトの設置不可

### ウェイレイ

**サチュレート**
- 行動妨害時間: 4秒 → **3秒**

**コンバージェントパス**
- アルティメット発動時の残像削除
- 行動妨害時間: 7秒 → **6秒**
- 発動時間: 2秒 → **1秒**
- 範囲幅: 18m → **13.5m**
- 移動速度上昇: 15% → **10%**

### レイズ

**ブラストパック**
- 滞空時にスロウの影響を受けるように変更

## センチネル大幅調整

センチネルは陣地防衛の要として、より明確な駆け引きができるように調整されました。

### ヴァイス

**アークローズ**
- フラッシュ予備動作開始時点で破壊可能に
- 成功時の通知削除
- フラッシュ時間: 2.25秒 → **2.0秒**
- 破壊後クールダウン: 45秒 → **60秒**

**シアー**
- 発動条件を調整し、より使いやすく変更

**レーザーヴァイン**
- 体力: 40 → **20**

**スチールガーデン**
- 発動時間: 3.4秒 → **4.4秒**
- 半径: 32.5m → **26m**

### サイファー

**スパイカメラ**
- **ステルス機能追加**
- 非アクティブ時8m以内で発見可能
- アクティブ時12m以内で作動音聴取可能
- 破壊時クールダウン: 45秒 → **60秒**

**トラップワイヤー**
- 発動時間短縮: 1.5秒 → **0.9秒** (PC版)
- スタンと麻痺デバフ削除
- 即座にスロウ状態に変更

### キルジョイ

**タレット**
- 破壊時クールダウン: 45秒 → **60秒**
- 再起動時間: 0.5秒 → **2秒**
- タギング移動速度低下: 29.5% → **50%**

**アラームボット**
- 体力: 50 → **20**
- 再起動時間: 1秒 → **2秒**

### デッドロック

**グラヴィネット**
- クールダウン: 40秒 → **60秒**

**バリアメッシュ**
- 体力: 400 → **300**
- ミニノード体力: 570 → **480**

**ソニックセンサー**
- スタン時間: 3.5秒 → **2.5秒**

### セージ

**バリアオーブ**
- 体力: 400 → **300**
- 生成時間: 3.3秒 → **2秒**
- バリア体力: 800 → **600**

## まとめ：パッチ11.08で変わること

### プレイヤーへの影響

1. **イニシエーター使用時**
   - クールダウン延長により、より計画的な使用が必要
   - フラッシュは強化され、戦闘開始のツールとして信頼性向上

2. **センチネル使用時**
   - オブジェクト体力減少により、破壊が容易に
   - カウンタープレイの機会増加

3. **武器選択**
   - ライフルのスプレー射撃が近距離で有効に
   - サブマシンガンの差別化が明確に

4. **マップ戦略**
   - パール、アビスでサイト内戦闘が重要に
   - 新マッププールで戦略の見直しが必要

### 今後の展望

このパッチは、VALORANTをより戦術的で、駆け引きのあるゲームにするための大きな一歩です。アビリティーとガンプレイのバランスが改善され、プレイヤーの判断がより報われる環境が整いました。

適応には時間がかかるかもしれませんが、これらの変更は長期的にゲームをより健全でエキサイティングなものにするでしょう。
