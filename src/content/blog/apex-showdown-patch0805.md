## 【速報】ショーダウンで何が変わる？重要な変更点まとめ

![【速報】ショーダウンで何が変わる？重要な変更点まとめの画像](/pcgame/apex/patch/0805/wildcard.png)

Apex Legends「ショーダウン」がついに配信開始！今回のアップデートは**ゲームプレイを根本から変える大型アップデート**です。新システムの追加からレジェンドの大幅強化まで、プレイヤーに大きな影響を与える変更が盛りだくさんです。

### 今回の最重要ポイント

- **レジェンド増幅器**：ゲームの流れを変える新パッシブアイテム
- **エリート武器**：RE-45バーストが期間限定で登場
- **バンガロール＆コースティック大幅強化**
- **ランクマッチのドロップゾーン導入**
- **ホップアップシステムの完全変更**

## ゲームプレイを変える3つの新要素

### 1. レジェンド増幅器（全5種類）

**紫ティアの新アイテム**として登場する増幅器は、ゲームの戦略を大きく変える要素です。

#### 増幅器一覧と効果

| 増幅器名 | 効果 | 戦略的価値 |
|---------|------|-----------|
| **無限弾薬増幅器** | ケアパッケージ以外の武器で無限弾薬 | 終盤の継戦能力が格段にアップ |
| **バッテリー無限増幅器** | バッテリーが消費されない | シールド回復の心配が不要に |
| **オーバーアーマー増幅器** | シールド容量+25 | 生存率大幅向上 |
| **オーバーフロー回復増幅器** | セル・注射器使用後に自動回復 | 回復アイテムの節約が可能 |
| **パワーブースト増幅器** | アビリティのクールダウン短縮 | アビリティ中心の戦術が強化 |

**入手方法**
- ケアパッケージ、保管庫、ホットゾーン
- ミシック・レジェンダリー・拡張・武器サプライボックスから確定入手
- ボックスリセット後は全ボックスで高確率スポーン

### 2. エリート武器：RE-45バースト

バリスティックのプライベートコレクションから**RE-45バースト**が期間限定で登場！

**主な特徴**
- ライトアモ → **エネルギーアモに変更**
- **3連バーストの新スピンアップシステム**
- 通常のRE-45オートは一時的にフロアアイテムから削除

### 3. ロックされたホップアップシステム

**ホップアップが拾えなくなり**、各武器に最初から装備される革新的なシステムです。

#### 新システムの仕組み

1. **ホップアップはすべて武器に内蔵**（最初は未発動状態）
2. **敵にダメージを与えてポイント獲得**
3. **ポイントが貯まると自動でホップアップが発動**
4. **ホップアップブースターで即座に発動可能**

#### ホップアップ別必要ポイント

- **アクセラレーター**：150ポイント（ピースキーパー、L-STAR、オルタネーター）
- **ガンシールドジェネレーター**：250ポイント（ヘムロック、R-301、ランページ）
- **セレクトファイアレシーバー**：250ポイント（チャージライフル、プラウラー）
- **らくがきMOD**：300ポイント（ボルト、スピットファイア、EVA-8）
- **スカルピアサー**：400ポイント（ウィングマン、ロングボウ、30-30）

## レジェンド大幅強化！バンガロール＆コースティック復活

### バンガロール：機動力と破壊力の両立

#### アビリティ強化

**戦術「スモークランチャー」**
- ガスキャニスターが**ドアを破壊して突き抜ける**
- 発射体速度：2500 → **2900に向上**
- クールダウン：35秒 → **30秒に短縮**
- 取り出し時間：0.35秒 → **0.25秒に短縮**

**アルティメット「ローリングサンダー」**
- クールダウン：270秒 → **210秒に大幅短縮**
- 発射アニメーション：5フレーム → **1フレームに高速化**

#### 新アップグレード

**レベル2「帯電煙幕」**
- 戦術アビリティを帯電させ、**敵のアルティメットに100ダメージ**
- **敵の戦術アビリティを破壊**

**レベル3「ECMペイロード」**
- アルティメットを帯電させ、**ダメージ+10**
- **敵の展開型アイテムを破壊**

### コースティック：致命的なガス攻撃の復活

#### Noxガス大幅強化

**ダメージ増加**
- 従来：4～10ダメージ
- **新仕様：10～15ダメージ**

**新効果追加**
- **ダメージを受けるとカメラが揺れる**
- **敵の移動速度を即座に減速**
- **移動系クールダウンを奪う**
- **ガス中ではコースティックの体力バーが非表示**

#### 戦術「Noxガストラップ」強化

- トラップ体力：150 → **225に増加**
- 発動半径：140 → **260に拡大**
- ガス半径：282 → **300に拡大**
- 持続時間：11秒 → **22秒に倍増**

#### 新パッシブ「フィールドリサーチ」

- **敵への毒付与**、**デスボックス開封**、**リングコンソールスキャン**で研究ポイント獲得
- **100ポイントごとにアップグレードポイント獲得**（最大2ポイント）
- **全4アップグレードを同時アンロック可能**（シリーズ初）

## ランクマッチ革命：ドロップゾーン導入

![ランクマッチ革命：ドロップゾーン導入の画像](/pcgame/apex/patch/0805/patch4.png)

### ドロップゾーンシステム

**従来の問題点**
- ドロップ地点の運ゲー要素
- 同じ場所に複数部隊が集中
- マッチ開始前から勝敗が決まるケース

**新システムの改善点**
1. **部隊ごとに探索地点を自動割り当て**
2. **レジェンド選択前にマップ確認可能**
3. **近くの敵部隊は危険地帯としてマーク**
4. **アイテムが均等分散（ホットゾーンなし）**

### ランクポイント調整

#### マッチ参戦コスト変更
- ブロンズ：0RP → **10RP**
- ゴールド：35RP → **38RP**
- プラチナ：45RP → **48RP**

#### チャレンジャーボーナス拡充
上位ランクの敵を倒すと**最大+50%のボーナス**：
- 1ティア上：+15%
- 2ティア上：+25%
- 3ティア上：+35%
- 4ティア以上：+50%

## 武器バランス調整

### ケアパッケージ変更

**新登場**
- **アキンボP2020**：ダメージ24 → 25、リロード時間短縮、腰だめ精度向上

**復帰**：
- **ピースキーパー**：マガジン5 → 6発、ただしチョーク時間増加、拡散拡大

### LMG全般ナーフ

**対象武器** ディヴォーション、スピットファイア、ランページ
- **腰だめ撃ちの拡散範囲拡大**
- 近距離での圧倒的な火力を調整

### ショットガン調整

**EVA-8**
- 1ペレットダメージ：6 → **7に増加**
- 連射速度は低下でバランス調整

**モザンビーク**
- **拡散パターンが狭くなり命中精度向上**
- **連射速度増加**でより使いやすく
