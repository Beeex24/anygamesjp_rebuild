## 【速報】エルマ・ルー＆コニィ・ルー、ドロシーの獣神化・改が遂に解禁！

モンスターストライク（モンスト）にて、**2025年9月2日（火）12:00**から「エルマ・ルー＆コニィ・ルー」と「ドロシー」の**獣神化・改**が解禁されることが発表されました！

両キャラクターとも人気の高いキャラクターで、獣神化・改によってさらなる強化が期待されています。この記事では、解禁される2体の詳細情報と必要素材について詳しく解説します。

## 解禁日時・基本情報

### 解禁日時
**2025年9月2日（火）12:00**

### 対象キャラクター
- エルマ・ルー＆コニィ・ルー
- ドロシー

両キャラクターとも★6まで進化可能となり、より強力な性能を発揮することができるようになります。

## エルマ・ルー＆コニィ・ルーの獣神化・改詳細

![エルマ・ルー＆コニィ・ルーの獣神化・改詳細の画像](/mobilegame/monsuto/shinka/erma/erma1.png)

### 基本情報
- **属性**: 木属性
- **レア度**: ★6
- **キャラクター名**: 絆を貫く修の武盗家 エルマ・ルー＆コニィ・ルー

エルマ・ルー＆コニィ・ルーは木属性のキャラクターとして獣神化・改が可能になります。「絆を貫く修の武盗家」という称号からも分かるように、2人の絆をテーマにした強化が施されることが予想されます。

### 必要素材一覧

エルマ・ルー＆コニィ・ルーの獣神化・改に必要な素材は以下の通りです

| 素材名 | 必要個数 |
|--------|----------|
| 獣神竜・碧 | 6個 |
| 獣神竜・光 | 4個 |
| 獣神玉 | 2個 |
| 碧獣玉 | 30個 |
| 碧獣石 | 50個 |

### 素材収集のポイント

**獣神竜・碧**と**獣神竜・光**の入手が最も重要になります。これらの素材は期間限定クエストや特定のイベントでしか入手できないため、事前に準備しておくことをおすすめします。

**碧獣玉**や**碧獣石**は比較的入手しやすい素材ですが、大量に必要となるため、日頃からコツコツと集めておきましょう。

## ドロシーの獣神化・改詳細

![ドロシーの獣神化・改詳細の画像](/mobilegame/monsuto/shinka/erma/erma2.png)

### 基本情報
- **属性**: 光属性
- **レア度**: ★6
- **キャラクター名**: 時空を超え行くオズの魔法使い ドロシー

ドロシーは光属性として獣神化・改が実装されます。「時空を超え行くオズの魔法使い」という名前から、オズの魔法使いをモチーフにした強力な能力を持つことが期待されます。

### 必要素材一覧

ドロシーの獣神化・改に必要な素材は以下の通りです

| 素材名 | 必要個数 |
|--------|----------|
| 獣神竜・光 | 6個 |
| 獣神竜・蒼 | 4個 |
| 獣神玉 | 2個 |
| 光獣玉 | 30個 |
| 光獣石 | 50個 |

### 素材収集の戦略

ドロシーの場合、**獣神竜・光**が6個と最も多く必要になります。光属性の獣神竜は入手機会が限られているため、イベント期間中に積極的に収集しましょう。

**獣神竜・蒼**も4個必要となるため、両方の獣神竜をバランス良く集めることが重要です。

## 獣神化・改のメリットと注意点

### 獣神化・改の主なメリット

1. **ステータスの大幅強化**
   - HP、攻撃力、スピードが大幅にアップ
   - より高難度クエストでの活躍が期待

2. **新アビリティの追加**
   - 既存のアビリティに加えて新たな能力が追加される可能性

3. **友情コンボの強化**
   - より強力な友情コンボへとパワーアップ

4. **ストライクショットの改良**
   - 威力や効果範囲の拡大が期待

### 注意すべきポイント

- **素材の準備が重要**: 獣神竜は入手機会が限られているため、事前準備が必須
- **進化は不可逆**: 一度獣神化・改を行うと元に戻すことはできません
- **運極作成の計画**: 運極を作成する場合は、十分な数のキャラクターを確保してから進化させましょう

### エルマ・ルー＆コニィ・ルー（木属性）の活用場面

- **木属性縛りクエスト**での主力として活躍

### ドロシー（光属性）の活用場面

- **光属性縛りクエスト**での切り札として
- **高難度クエスト**でのアタッカー役として期待
